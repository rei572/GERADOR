# Corrente do Trafo

App de campo para dimensionar gerador, trafo, cabos e eletrocentro.

Abas:
- **Trafo** — corrente nominal, inrush, curto, cabos, carga medida e eletrocentro sugerido (trafo 1.500/2.000 kVA + 1 a 3 geradores de 940 kVA).
- **Gerador** — gerador sugerido em prime, comparação com o gerador disponível, fator de pico por tipo de cliente, cabos com neutro, regra rápida para gerador tri em carga bifásica.
- **Motor** — até 5 motores, partida escalonada ou junta, gerador e cabos.
- **Pico** — corrente no gerador pelo trafo YNd1, divisão de carga entre geradores em paralelo e risco de Reverse Power.

Funciona sem internet: abra o `index.html` no navegador do celular.
